# Changelog

## 0.1.0 - 2026-11-24

First public version.

- `project-setup` skill: preflight, interview, recap, then scaffold, GitHub, database (Neon with Neon Auth, or Supabase), Vercel, founding documents, analytics (PostHog or Amplitude), email (Resend or Plunk) and Claude Code cloud sessions.
- Companion panel: a local page that shows progress and takes API keys so they never pass through the chat.
- Optional key vault (`scripts/vault`): the API keys of your own accounts in one Vercel project, shared by every project and by cloud sessions.
- Installable as a Claude Code plugin.
